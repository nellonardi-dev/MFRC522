# Contributing

Grazie per l'interesse nel progetto.

- Aprire una issue per segnalare bug o proporre modifiche.
- Descrivere scheda, core Arduino, cablaggio e versione del modulo MFRC522.
- Per le pull request, spiegare la modifica e indicare gli sketch/prove eseguiti.
- Evitare modifiche non correlate nella stessa pull request.
